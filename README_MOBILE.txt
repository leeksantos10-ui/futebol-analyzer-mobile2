FUTEBOL ANALYZER V6 MOBILE

Arquitetura preparada para servidor online.
- Sem 192.168.x.x / localhost no celular.
- Interface responsiva para celular e PC.
- Banco atual mantido: 15.323 jogos.
- Perfis de estratégia.
- Importação de Excel (.xlsx) e CSV com prévia.
- Detecção de duplicados por Data + Hora + Confronto + Campeonato.
- Opção de atualizar jogos existentes durante a importação.
- Relatório mensal e lucro por campeonato em unidades/ROI.
- Odds de 1X2, Over e BTTS disponíveis como métricas.

A migração definitiva para PostgreSQL/Supabase será feita depois que o layout e o importador forem validados.
